# \# 数独游戏 (Sudoku Game)

# 

# 一个使用 Godot 4.6 开发的经典数独游戏，支持多种难度级别、模式切换、自动求解和音效系统。

# 

# \## 功能特性

# 

# \### 游戏模式

# \- \*\*做题模式\*\*：根据难度生成数独题目，挑战解题

# \- \*\*创造模式\*\*：自由编辑数独，可导入导出保存

# 

# \### 难度级别

# | 难度 | 移除数字数量 | 说明 |

# |------|-------------|------|

# | 简单 | 30 | 适合新手入门 |

# | 中等 | 40 | 一般玩家 |

# | 困难 | 50 | 有挑战性 |

# | 极难 | 60 | 高难度挑战 |

# 

# \### 核心功能

# \- 9×9 数独棋盘，宫格边界粗线区分

# \- 点击选中格子高亮同行、同列、同宫格

# \- 数字键盘（1-9）+ 清除按钮

# \- 支持键盘输入（数字键 + Backspace/Delete）

# 

# \### 辅助功能

# \- \*\*校验\*\*：检查当前填入数字是否正确

# \- \*\*求解\*\*：自动求解数独（回溯算法）

# \- \*\*清空\*\*：一键清除所有用户输入

# \- \*\*清除\*\*：清除当前选中格子

# \- \*\*新游戏\*\*：重新开始

# 

# \### 导入导出

# \- 支持将游戏状态导出为 JSON 文件

# \- 支持从 JSON 文件导入恢复游戏

# \- 弹出系统文件管理器选择路径

# \- 文件名自动按时间戳生成

# 

# \### 音效系统

# \- 背景音乐循环播放（2首）

# \- 按钮点击音效

# \- 校验成功/失败音效

# \- 游戏完成音效

# \- 音量调节面板（BGM / 音效独立控制）

# \## 算法说明

# 

# \### 数独生成

# 使用递归回溯算法生成完整数独解答，然后根据难度移除相应数量的数字。

# 

# \### 数独求解

# 使用递归回溯算法尝试填入1-9，验证每个数字的有效性，直到找到解或确定无解。

# 

# \### 有效性检查

# \- 行检查：同一行不能有重复数字

# \- 列检查：同一列不能有重复数字

# \- 宫格检查：同一3×3宫格不能有重复数字
